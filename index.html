// things I've actually built

mini-vLLM

an LLM inference server, from scratch

Python · PyTorch · Triton

I wanted to see where serving falls apart, not read about it secondhand, so I built my own inference server. I wrote a continuous-batching scheduler for Qwen2.5-1.5B on an L4, profiled it, and found cache copying was quietly eating 57% of runtime. Rewriting that path got me 1.5x the throughput at 1.5x lower P99 latency.

Then the part I'm weirdly proud of. I added a paged KV cache to fit 3–5x more requests in the same memory (40% → 95% utilization)… and it made decode 2.87x slower. PyTorch was copying the scattered cache blocks every single step. So I wrote a Triton kernel that reads the blocks straight from the cache and skips the copy entirely.

still a work in progress. that kernel makes me irrationally happy.

Fere

the dev tool I couldn't stop building

Understanding your own local dev environment shouldn't take three terminal tabs and a guess. Fere auto-discovers the services you've got running and draws a live topology graph, then traces request flow by intercepting traffic between them — so you can actually watch how a request moves through your stack.

There's also Sentinel, an in-app agent that flags issues with one-click fixes and hands the genuinely hard ones off to coding agents over Fere's MCP server.

co-founded this one. it took 2nd place and $10k at Cal Poly Innovation Quest, which still feels a little unreal.

Hybrid Search Engine

a Rust rabbit hole

Rust

I wanted to know how far I could push search relevance without wrecking tail latency. So I wrote one. It mixes BM25 with HNSW vector search over 50K MS MARCO passages and scores 0.888 MRR — beating keyword-only by 23.7% and vector-only by 1.4%.

The fun constraint was the tail: it holds p99 query latency under 20ms across every mode, because Rust keeps GC pauses out of the picture entirely. I also wrote a custom score fusion so a hybrid result can never rank worse than vector search alone, which nudged Recall@100 up to 98.85%.

Rust fought me the whole way. worth it.
