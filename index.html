mini-vLLM

LLM inference server

Python · PyTorch · Triton

An LLM inference server built from scratch to study where serving actually bottlenecks.

  • Built a continuous-batching scheduler from scratch for Qwen2.5-1.5B on an L4 GPU. Profiling showed cache copying ate 57% of runtime; rewriting that path got 1.5x throughput at 1.5x lower P99 latency.
  • Added a paged KV cache that fits 3–5x more concurrent requests in the same memory, taking KV utilization from 40% to 95%.
  • Found that paging made decode 2.87x slower because PyTorch copied the scattered blocks every step, then wrote a Triton kernel that reads the blocks straight from the cache and removes the copy.
